# Alembic
Alembic: An extendable system for augmenting human intelligence. It combines a cloud-based knowledge graph with a secure, locally-controlled agent for executing complex tasks.

Project Alembic is an integrated system designed to function as a true "Extended Mind." Its goal is to fundamentally augment human intelligence and creativity by transforming how we interact with personal knowledge and AI.

At its core, Alembic allows users to build a dynamic knowledge graph, distilling scattered information, notes, and ideas into a network of interconnected, actionable insights.

This system extends beyond passive knowledge storage, utilizing a secure "Local Agent" that runs on the user's device. This agent acts as the system's hands, capable of executing complex, real-world tasks—from building applications to interacting with external APIs—using the user's own credentials, which are never exposed to the central server.

This unique "Cloud Thinking, Local Acting" architecture ensures that while the system benefits from the immense power of cloud-based AI, it remains fundamentally secure, robust, and efficient, giving users absolute control and ownership of their digital lives. The ultimate mission is to remove the fiction from science fiction, creating a practical and powerful AI partner.
